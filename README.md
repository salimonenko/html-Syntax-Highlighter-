# html-Syntax-Highlighter-
highlightHTML(code) — раскрашивает HTML-код, оборачивая теги, атрибуты, значения, кавычки, комментарии, скрипты и текст в &lt;span> с CSS-классами.


Простой малоресурсный скрипт для подсветки HTML-синтаксиса. Занимает объем менее 1 кБ. Не требует установки громоздких библиотек и зависимостей.
Пример работы - test.html.
Ограничения:
1. Нельзя использовать символы & < > нигде, за исключением обозначения тегов, комментариев и javascript-кода, оформленного тегами <script> ... </script>. Т.е. указанные символы нельзя использовать в именах атрибутов, в текстовом содержимом тегов (элементов). Но, их можно в комментариях вида
